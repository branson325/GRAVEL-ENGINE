# GRAVEL 1.0.2 — Stability and Workflow Update

- Improved project startup flow with clearer welcome-screen actions and better guidance for empty folders.
- Refined file and folder management so new files and projects feel more predictable and easier to navigate.
- Strengthened save-state handling for untitled files, unsaved changes, and file-closing warnings.
- Improved run feedback so successful executions, failures, and user-stopped runs are easier to distinguish.
- Added clearer launch-error messaging when a required runtime is missing or fails to start.
- Improved app polish by keeping the editor title, status feedback, and save prompts more consistent during use.
- Continued refining the overall user experience for creating, editing, running, and managing code files.
- Preserved the existing unsaved-change indicator, deletion confirmations, and general editor behavior while improving stability.
- Added a GRAVEL-themed, pixel-style file picker for opening files, choosing project folders, and Save As.
