# GRAVEL 1.0.4 — Editor and Runtime Update

- Added syntax highlighting for JavaScript, Java, and C/C++ source files.
- Added persistent editor font-family and font-size preferences in `~/.gravel/settings.json`.
- Added editor line numbers and automatic bracket/quote pairing.
- JSON Run now formats valid JSON in the editor and terminal.
- Added optional GCC/G++ compilation and execution with temporary binaries cleaned up after the run.
- Streamed Ollama responses into the chat and added a **Fix with GRAVEL AI** action after failed runs.
