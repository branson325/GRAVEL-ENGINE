# GRAVEL BETA 1.0.8 - Workspace Polish, Better Flow, Smoother Coding

- Updated the version branding across the app, welcome screen, and file title bar to reflect the 1.0.8 release.
- Set AI Assistant to start in chat mode; editing the open file is now an explicit opt-in.
- Made AI response-card accents follow the selected theme instead of using a fixed red color.
- Added the Signal theme, with deep charcoal surfaces, cool syntax colors, and cyan accents across the workspace.
- Refined explorer, terminal, and AI panel headings plus the status bar to match the active palette.
- Refined the overall workspace feel with cleaner visual polish and more consistent editor styling.
- Added a breadcrumb header and status bar that tracks the cursor position.
- Added familiar File, Edit, View, Go, and Run menus, including editor actions and Go to Line.
- Restored the project explorer sidebar as part of the default workspace, while keeping its View menu toggle.
- Removed the separate single-file tab and placed the current filename at the top-right.
- Set the small GRAVEL logo as the application window icon in the top-left, replacing the default icon.
- Set a stable Windows app identity and provide 16px/32px GRAVEL window icons for taskbar display.
- Added a creator credit beside Run with the supplied profile picture, username, and clickable email contact.
- Tightened workspace spacing and added consistent editor, panel, and status accents for a more VS Code-inspired layout.
- Improved the welcome screen messaging to highlight the newer, smoother workflow focus.
- Kept the editor's core features stable while making the interface feel more polished and modern.
- Continued to improve the project workspace experience with clearer file status awareness and smoother app presentation.
- Preserved multi-language runtime support, AI assistance, theme customization, and file management workflows.
- Focused 1.0.8 on reducing friction and making GRAVEL feel more like a comfortable coding workspace than a basic editor.

## Notes

This release is an interface and flow-focused update: the app remains lightweight, but it feels more intentional, consistent, and easier to work in day to day.

### Highlights

- Better identity and version clarity across the desktop app
- Smoother welcome experience and polished app presentation
- More focused workspace feel for daily coding sessions
- Continued stability for AI, file management, and editor tools
