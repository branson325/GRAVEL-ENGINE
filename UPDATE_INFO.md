# GRAVEL 1.0.1 — User Experience Update

- Added welcome-screen actions to open a project folder, open a file, or create a new file.
- Added guidance for empty projects and clearer feedback when creating a new file.
- Clarified unsaved-file state and prevented autosave prompts before an untitled file has a save location.
- Added save, discard, or cancel protection when leaving an unsaved untitled file without a project folder.
- Improved run feedback to distinguish successful runs, failures, and runs stopped by the user.
- Improved launch-error details when a required runtime cannot start.
- Renamed the application window to "GRAVEL Code Editor" and "GRAVEL".
- Kept the existing unsaved-change indicator and file/folder deletion confirmation.
